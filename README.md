# Política de Privacidad — Reino Oscuro Gaming

Página de Política de Privacidad para la comunidad gaming **Reino Oscuro**, redactada conforme al **RGPD** (Reglamento General de Protección de Datos) y la **LOPDGDD** española.

## Contenido

El documento cubre las siguientes secciones:

1. Responsable del Tratamiento
2. Datos que Recopilamos
3. Finalidad del Tratamiento
4. Base Legal del Tratamiento
5. Cookies y Tecnologías Similares
6. Compartición de Datos con Terceros
7. Conservación de Datos
8. Tus Derechos (acceso, rectificación, supresión, oposición, portabilidad, limitación)
9. Seguridad
10. Menores de Edad
11. Cambios en esta Política
12. Contacto

## Estructura de archivos

```
/
├── politica-de-privacidad.html ← Este archivo
├── terminos-de-servicio.html   ← Documento relacionado
└── logo_rog.png                ← Logo requerido (debe estar en la misma carpeta)
```

## Requisitos

- El archivo `logo_rog.png` debe estar en la **misma carpeta** que el HTML.
- No se necesitan dependencias adicionales. Las fuentes se cargan desde Google Fonts (requiere conexión a internet).
- Compatible con todos los navegadores modernos.

## Personalización

| Qué cambiar | Dónde encontrarlo |
|---|---|
| Datos del responsable del tratamiento | Sección I — Responsable del Tratamiento |
| Edad mínima permitida | Sección X — Menores de Edad |
| Plazo de conservación de datos | Sección VII — Conservación de Datos |
| Plazo de respuesta a solicitudes | Sección XII — Contacto |
| Fecha de actualización | Cabecera del documento (`update-badge`) |
| Colores principales | Variables CSS en `<style>` (`:root`) |

## Cumplimiento normativo

Este documento está redactado como punto de partida orientativo para el cumplimiento del RGPD y la LOPDGDD. Se recomienda **revisarlo con un asesor legal** antes de publicarlo, especialmente si la plataforma realiza tratamientos de datos complejos o procesa datos de menores.

## Enlace entre documentos

Este archivo enlaza automáticamente a `terminos-de-servicio.html` desde el footer. Ambos documentos deben estar en la misma carpeta para que el enlace funcione correctamente.
